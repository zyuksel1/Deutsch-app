# Deutsch-App
Türkçe konuşanlar için A1'den başlayan Almanca öğrenme uygulaması. Kurulum gerektirmez; telefonda "Ana ekrana ekle" ile uygulama gibi açılır ve çevrimdışı çalışır.
İlerleme yalnız cihazın tarayıcısında saklanır (localStorage); cihazlar arası taşıma için uygulamadaki 💾 İlerleme yedeği kullanılır.
Yerelde çalıştırma: `start.cmd` (Windows, http://localhost:8080).
